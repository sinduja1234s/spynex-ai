# SPYNEX AI — AI-Based Statistical Trap Detector

Enterprise dark-mode AI analytics dashboard built with **Flask (Python)**, **SciPy**, **Scikit-Learn (Isolation Forest)**, and **Chart.js**.

## Quick Start
```bash
cd spynex_ai_statistical_trap_detector
pip install -r requirements.txt
python app.py
```
Open `http://127.0.0.1:5000` in your browser.
